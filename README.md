# What is this ?

This Godot project template contains the following features to help you get started :
- a gameboy shader ([guide](GUIDE_SHADER.md))
- a cool customizable splash screen
- a Github actions configuration to automatically build and deploy your project every time you boot ([guide](GUIDE_GITHUB_ACTIONS.md))

# What do I need to know before I use this ?
- basic git knowledge (clone, commit, push)
- basic Godot knowledge (this is a godot project after all)

# How do I use this ?
- Click the "use this template" button on the top right of this page
- name your project accordingly
- when it's finished, clone the project on your machine
- open the Godot launcher
- click "import" and choose the directory you just cloned
- enjoy !

Note : to use the automatic build every time you push, follow the guide [here](GUIDE_GITHUB_ACTIONS.md).
